# Entheogenous — Fractal Art Portfolio

Portfolio website for **Entheogenous** (@entheogenous / Fractal Geek).
Showcase of psychedelic, mathematical, and algorithmic fractal art.

- **Categories**: Photos (High-Resolution Stills) & Motions (Animations / Video)
- **Design System**: Editorial cinematic darkroom inspired by RunwayML
- **Palette**: Pure black (`#000000`) with luminous fractal contrast, zero shadows
- **Built with**: Pure HTML5, CSS Grid, JavaScript (Single-file, ultra-fast)

## Live Site
Visit: [https://mjavadz.github.io/entheogenous/](https://mjavadz.github.io/entheogenous/)

## Structure
- `index.html` — The complete portfolio application
- `photos/` — High-res fractal images and WebP thumbnails
- `motions/` — Motion loops and animations
